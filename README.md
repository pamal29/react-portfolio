# 🌐 React Portfolio

A modern **developer portfolio website** built with **React** to showcase my skills, projects, and experience.
This portfolio highlights my work, technologies I use, and provides a way for recruiters or collaborators to connect with me.

🔗 **Live Demo:**
https://react-portfolio-iota-ruby.vercel.app/

---

## 🚀 Features

* 🎨 Modern and responsive UI
* ⚡ Built with React for fast performance
* 📱 Mobile-friendly design
* 🧑‍💻 About section introducing my background
* 🛠️ Skills and technologies showcase
* 📂 Projects section highlighting my work
* 📬 Contact section to get in touch

## ⚙️ Installation & Setup

Clone the repository

```
git clone https://github.com/pamal29/react-portfolio.git
```

Navigate to the project folder

```
cd react-portfolio
```

Install dependencies

```
npm install
```

Run the development server

```
npm start
```

The application will run at

```
http://localhost:3000
```

---

## 🌍 Deployment

This project is deployed using **Vercel**.

To deploy your own version:

1. Push your project to GitHub
2. Connect the repository to Vercel
3. Deploy automatically
